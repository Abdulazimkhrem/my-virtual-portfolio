# Abdulqader Ghallab — Developer Portfolio

A bilingual, responsive portfolio website built with HTML, Tailwind CSS, and vanilla JavaScript. It showcases a modern neon-cyan design, light/dark mode, animated sections, a project request form with EmailJS OTP verification, a live price estimator, and a request status tracker.

> This is a fictional pilot project and my first standalone web application.

## English

### Overview
This project is a personal portfolio website designed to look polished, modern, and interactive. It is built as a single-page experience with a strong visual identity and multiple user-facing features.

### Key Features
- Full Arabic/English support with instant language switching
- Light and dark theme toggle with saved preference
- Responsive profile section with social links and animated visuals
- Collapsible navigation and smooth-scroll sections
- Project request form with validation and EmailJS verification
- Live price estimation based on page count
- Request tracking with status display
- Accessible structure with ARIA labels and semantic HTML

### Tech Stack
- HTML5
- Tailwind CSS
- Remix Icon
- EmailJS
- Vanilla JavaScript
- localStorage for theme and language preferences

### Project Structure
- index.html — main page structure
- my-portfolio-js.js — app logic, translations, and interactions
- my-portfolio-photo.jpg — profile image
- audio-intro.mp3 — intro audio
- video-intro.mp4 — intro video
- README.md — project documentation

### How to Run
1. Clone or download the project.
2. Make sure the assets are in the same folder as index.html.
3. Open index.html directly in your browser.

### Customization
- Change the neon-cyan theme color from the Tailwind classes.
- Update text and translations in the language dictionary inside my-portfolio-js.js.
- Replace the placeholder profile details and media files with your own.
